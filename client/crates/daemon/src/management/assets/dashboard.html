PortZero Local

Local dashboard

Give any local app a real name — myapp.portzero.local — instead of juggling ports. Set PZ_TUNNEL when you start it, and the daemon routes the name to it.

Settings

Saved to ~/.portzero/config.toml and applied live.

Getting Started

Download the examples, then run one. Each example sets PZ_TUNNEL and starts a small web app — the commands are shown so you can see exactly how it works.

Clones github.com/PortZeroNetwork/portzero-examples to ~/portzero-examples.
